Model Equations

Derived parameters: $k_c = k_j / 3$ (critical density)  |  $q_c = v_f \cdot k_c / 2$ (capacity flow)  |  $v_c = v_f / 2$ (critical speed)

Uncongested branch ($k \leq k_c$):   $v(k) = \dfrac{q_c \left(2 k_c - k\right)}{k_c^2}$

Congested branch ($k > k_c$):   $v(k) = \dfrac{q_c}{k} \left[1 - \dfrac{(k - k_c)^2}{(k_j - k_c)^2}\right]$

Fundamental identity:   $q = k \cdot v(k)$

Inverse MFD ($0 \leq q \leq q_c$):

Free-flow:   $k(q) = k_c \left(1 - \sqrt{1 - \dfrac{2q}{v_f k_c}}\right)$

Congested:   $k(q) = k_c + (k_j - k_c)\sqrt{1 - \dfrac{2q}{v_f k_c}}$

Static surrogate options (single-valued demand-based costs):

Queue-delay:  

$$t^{queue}(q) = \begin{cases} t_{run}(q), & q \leq q_c \\ t_c + \dfrac{H}{2}\left(\dfrac{q}{q_c} - 1\right), & q > q_c \end{cases}$$

Steep tail:  

$$t^{tail}(q) = \begin{cases} t_{run}(q), & q \leq q_c \\ t_c \left(\dfrac{q}{q_c}\right)^{20}, & q > q_c \end{cases}$$

Wardrop relative gap:   $\text{gap} = \dfrac{\sum_a V_a \cdot t_a}{\sum_{rs} d_{rs} \cdot \pi_{rs}} - 1$   where $t_a = L_a / v_a$ is link travel time, $\pi_{rs}$ is shortest-path cost.

Extended demand → density mapping (§10, for flow-based assignment):

$$k(q) = \begin{cases} k_c \left(1 - \sqrt{1 - \dfrac{q}{q_c}}\right), & q \leq q_c \\[6pt] k_c + (k_j - k_c)\sqrt{1 - \dfrac{q_c}{q}}, & q > q_c \end{cases}$$

Cost chain: $q \xrightarrow{k(q)} k \xrightarrow{v(k)} v \xrightarrow{L/v} t$   — monotone for all $q \geq 0$, guaranteeing MSA convergence.

Per-link kc calibration (§11, from intersection spacing $d$):

$$\frac{k_c}{k_j} = 0.20 + \frac{0.25}{1 + e^{-0.003(d - 500)}}$$

Parameters (matching assignment defaults): $v_f$ = 60 km/h, $k_j$ = 150 veh/km, $k_c$ = 50 veh/km, $q_c$ = 1500 veh/hr, min speed = 0.01 km/h.

1. Speed–Density Relationship

The bi-parabolic model (Fournier) defines speed as a function of density using two branches joined at critical density kc = kj/3 = 50 veh/km. The uncongested branch (blue) is linear in v-k space: v(k) = qc(2kc − k) / kc². The congested branch (red) is parabolic in q-k space, yielding a nonlinear speed drop. At k = 0, v = vf = 60 km/h. At k = kc, v = vf/2 = 30 km/h. The junction is C¹-continuous (matching value and slope). A floor of 0.01 km/h prevents division by zero.

2. Flow–Density Fundamental Diagram (MFD)

This IS the macroscopic fundamental diagram. Both branches are downward-opening parabolas in q-k space with vertex at ($k_c$, $q_c$). Capacity flow $q_c = v_f \cdot k_c / 2$ = 1500 veh/hr occurs at critical density. The uncongested branch (left of $k_c$) is the operating regime for equilibrium assignment — the congested branch represents breakdown conditions where adding vehicles reduces throughput.

3. Speed–Flow Relationship

The characteristic backward-bending speed–flow curve, derived parametrically from {q(k), v(k)} as density sweeps from 0 to kj. On the uncongested branch (blue), increasing flow reduces speed — the familiar "more cars, slower travel" intuition. At capacity qc = 1500 veh/hr, speed is vc = vf/2 = 30 km/h. Beyond this point the curve bends backward: on the congested branch (red), both speed and flow decrease — the hallmark of traffic breakdown. This is the relationship most directly observed by highway sensors and loop detectors.

4. Flow–Travel Time (Cost Function)

Travel time $t = L / v$ for a 1 km link, plotted against flow. This is the link cost function that assignment directly optimizes. On the uncongested branch (blue), travel time rises monotonically from the freeflow time as flow increases toward capacity — the classical "congestion penalty." At capacity breakdown, the curve bends backward: on the congested branch (red), flow drops while travel time continues to spike. Near jam density, travel time diverges. This backward bend is why BPR-style $t(V)$ cost functions are monotonic approximations — they avoid the multi-valued regime. Our density-based VDF handles both branches natively via $t = L / v(k)$, where $k$ is always single-valued. See §10 for the monotone cost extensions that resolve the backward bend for assignment.

5. Queue Delay and Steep-Tail Static Surrogates

The backward-bending MFD is physically meaningful, but static assignment needs a single-valued cost curve in demand space. A queue-delay surrogate keeps the running time on the uncongested branch up to capacity and, for $q > q_c$, adds the average delay from a point queue that forms when arrivals exceed discharge:

$$t^{queue}(q) = \begin{cases} t_{run}(q), & q \leq q_c \\ t_c + \dfrac{H}{2}\left(\dfrac{q}{q_c} - 1\right), & q > q_c \end{cases}$$

where $H$ is the analysis period and $t_c = 2L/v_f$ is the running time at capacity. In this report the overlay uses $H = 1$ hour, so the queue penalty grows by 30 minutes for each additional capacity's worth of demand. The purple comparator is the proposed steep-tail extension $t^{tail}(q) = t_c (q/q_c)^{20}$ above capacity. It is numerically simple and monotone, but unlike queue delay it does not correspond to an explicit storage or discharge process.

6. Inverse MFD: Flow → Density

The closed-form inversion of the MFD. Given flow $q$, density on each branch is:

Free-flow:   $k(q) = k_c \left(1 - \sqrt{1 - \dfrac{2q}{v_f k_c}}\right)$

Congested:   $k(q) = k_c + (k_j - k_c)\sqrt{1 - \dfrac{2q}{v_f k_c}}$

Both branches exist only for $0 \leq q \leq q_c = 1500$ veh/hr. At $q = q_c$ they meet at $k_c = 50$. At $q = 0$, the free-flow branch gives $k = 0$ while the congested branch gives $k = k_j = 150$. Demand volumes exceeding $q_c$ are out of range — the link is over capacity and the inversion has no real solution, which is why convergence blending operates in volume space with a constant-factor density derivation.

7. Near-Jam Behaviour (k → kj)

This panel zooms into the congested branch near jam density to show the steep speed gradient that impacts convergence. At k/kj = 0.90, speed is just 3.1 km/h. At k/kj = 0.99 it drops to 0.30 km/h. This extreme sensitivity means a small density change near kj produces a large travel-time change — creating a near-discontinuity that Frank-Wolfe's linear search direction struggles to navigate.

Density is uncapped above kj: the VDF's speed floor (0.01 km/h) handles oversaturated links. Links exceeding kj represent virtual queue / spillback — physically impossible density but mathematically stable.

10. Extended Cost Chain for Flow-Based Assignment

The MFD inverse (§6) only exists for $q \leq q_c$. For flow-based assignment, we need a monotone mapping from any demand level to a unique cost. The extended q → k mapping provides this:

Uncongested ($q \leq q_c$):   $k(q) = k_c \left(1 - \sqrt{1 - \dfrac{q}{q_c}}\right)$   (exact MFD inverse, maps $[0, q_c] \to [0, k_c]$)

Oversaturated ($q > q_c$):   $k(q) = k_c + (k_j - k_c)\sqrt{1 - \dfrac{q_c}{q}}$   (asymptotic extension, maps $(q_c, \infty) \to (k_c, k_j)$)

The two pieces join at $q = q_c$ where both yield $k = k_c = 50$. As $q \to \infty$, density approaches $k_j = 150$ asymptotically — speed approaches zero but never reaches it, giving an unbounded, monotone cost function $t(q) = L / v(k(q))$.

11. Per-Link kc Calibration

The default model uses a fixed kc/kj ratio for all links. In reality, critical density depends on intersection spacing: dense urban grids with frequent signals reach capacity at lower density than uninterrupted highway segments.

We calibrate kc/kj per link using a logistic function of intersection distance (the cumulative link length between true intersections, where "true" means node degree > 2):

$$\frac{k_c}{k_j} = 0.20 + \frac{0.25}{1 + e^{-0.003 \cdot (d - 500)}}$$

This gives:

  • Urban grid (~100 m spacing): kc/kj ≈ 0.21 — capacity reached early, strong congestion sensitivity
  • Arterial (~500 m): kc/kj ≈ 0.33 — the classical default
  • Highway (>2 km): kc/kj ≈ 0.45 — links absorb more density before breakdown

Left panel: The logistic calibration curve. Right panel: Effect on the flow–density MFD — lower kc/kj shifts the capacity peak left (lower density, lower capacity flow) and creates a longer congested branch. This also distributes the qc gap across different density levels instead of concentrating it at one point.
